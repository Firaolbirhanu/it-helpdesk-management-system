# IT Help Desk & Service Management System

A full-stack IT Help Desk and Service Management System designed
to help organizations manage IT support requests, assign technicians,
track ticket progress, monitor SLAs, and generate support reports.

## Technologies

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
- SQLAlchemy

### Database
- PostgreSQL

### Authentication
- JWT
- Role-Based Access Control
